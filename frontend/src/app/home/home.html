Ask the papers

Every answer points to the passage it came from.

ResearchLens answers questions about four open-access papers on optical defect inspection. It uses only the papers’ text, cites each claim, and tells you when the papers don’t cover a question.

The four papers it reads

Open-access articles from Sensors and the Journal of Imaging, all licensed CC BY 4.0. Figures, tables and references are left out; formulas are rendered as readable text.

What the evaluation found

Retrieval and answers were scored on 50 development questions, 14 of which the papers cannot answer. A separate 36-question held-out set was run once, under decision rules written down before the run. The misses are reported too.

Run it on your own machine

The smallest setup uses TF-IDF and downloads no models. Without an OpenAI key it shows the ranked passages instead of a written answer, so you can still check what it would read. 

git clone {{ repository }}.git
cd ResearchLens
docker compose up --build
